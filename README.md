# 轻量级外卖平台实践（课程项目）

本仓库是课程项目「轻量级外卖平台仿饿了么」的唯一工作仓库，当前处于**从零开发、文档先行**阶段。

## 仓库拓扑

单仓库多目录（2026-09-01 确定，各端独立工程、独立进程、RESTful 通信）：

| 目录 | 承载内容 | 状态 |
| --- | --- | --- |
| `docs/**` | 课程文档与原型资产 | 持续更新 |
| `frontend/user-h5/` | 用户端移动 H5（Vue 3 + Vite + Pinia） | 待初始化 |
| `frontend/merchant-admin/` | 商家端桌面后台（React 18 + Vite + Ant Design 5，≥1280px） | 待初始化 |
| `backend/` | Java（Spring Boot）后端 | 待初始化 |

## 关键决策速览

- 前后端分离，接口统一 RESTful `/api/v1`；服务端 Session + Cookie 登录。
- 全程 TDD；需求变更后先补测试再实现，过程证据入 Git。
- 课程基础 P0 共六类：用户、商家（含商家注册）、店铺、商品、购物车、基础订单；订单状态 P0 仅 `PROCESSING` 单一状态。
- 商家端为**桌面 Web 后台**（React 18 + Vite + Ant Design 5，桌面优先 ≥1280px），不做移动端；桌面线框只承担布局示意，不承担 1:1 复刻义务。
- 用户端为移动端网页（Vue 3 + Vite + Pinia + Vue Router + Axios），遵守 `docs/frontend/UI复刻经验与执行约定.md` 中的 Figma exact 复刻经验。
- 商家测试账号 `merchant-a / 123456`（绑定店铺 `m002`）；商品编号 `p101` 起步；对外只返回稳定业务编号。
- 品牌强调色统一亮橙 `#ff5a1f`（商家端经 AntD `ConfigProvider` 配置）；红色仅用于错误、危险、未读等语义状态。
