### 2.2 结构改造

- **底部导航整体替换**：原稿为 5 Tab（含第三方应用 logo 与"购物车"Tab），已重绘为项目四 Tab：首页（选中态 `#ff5a1f` 实心 house）/ 消息（含未读红点，语义红）/ 订单 / 我的；黑条为 Home Indicator 装饰。
- **定位文案**：`万象城 ▾` → `天津大学软件园校区 ▾`（课程演示地址口径）。
- **状态栏**：顶部 `9:41` 状态栏为设计稿装饰，H5 实现不含，实现从定位与频道栏开始。

### 2.3 占位清单（新版多出元素，一律不可交互）

实现时点击一律提示"暂未开放"，不进入功能范围、不接入真实数据：

- 分类宫格超范围栏目：超市便利、水果鲜花、买菜、买药、跑腿（宫格实现时渲染课程 10 类点餐分类数据）。
- 活动区运营内容：饿小宝·囤好券/天天秒大牌/去秒杀、天天特价、在线拼单、天天爆红包、0元领水果。
- 筛选标签：换换口味、天天爆红包、减配送费、无门槛红包。
- 商家卡内：优享大牌、人气推荐、"近30日8139人逛过"、"预估价"（不得参与真实计价）。
- 频道："常点"频道（默认生效频道为"推荐"）。
