## 1. 使用方式

- **状态取值**：`待认领` / `进行中` / `待验证` / `已完成` / `已冻结（不做）`。
- **认领方式**：把"负责人"写成自己的名字、状态改为 `进行中`，并在小组群同步一句（**群聊只作通知，不作证据**，口径见 `docs/project/项目规则.md` §1.1）。
- **完成方式**：状态改 `已完成` 并填证据（PR 链接 / 提交号 / 记录文件路径）；未收口就如实写 `进行中`，**不得写成已完成**。
- **写权**：每人更新自己名下的行与状态；表格结构、批次顺序与认领仲裁由组长维护。
- **AI 代理**：可直接读取本表认领任务；更新状态时同步在 `docs/record/raw/YYYY-MM-DD/` 留痕。
