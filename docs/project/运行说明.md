# 运行说明

日期：2026-09-01；2026-09-02 新增第 4 节"服务器与部署"框架（具体方案由后端同学填写）

## 1. 当前状态：文档阶段，暂无本地运行命令

- 本仓库当前只包含课程文档与规划材料，没有前端或后端工程，因此没有 `npm install`、`npm run dev`、`npm run build` 之类的本地运行命令。
- 仓库结构（单仓库口径，依据课程要求"每组必须建立一个代码仓库"）：全组共用一个 Git 仓库，顶层规划 `frontend/user-h5/`（用户端移动 H5，Vue 3 + Vite + Pinia）、`frontend/merchant-admin/`（商家端桌面 Web 后台，React 18 + Vite + Ant Design 5）、`backend/`（Java 后端）、`docs/`（文档）；前后端分离指各端独立工程、独立进程、通过 RESTful 接口通信，不要求分仓库。
- 用户端 Vue 工程尚未初始化。后续将使用 `npm create vue` 在 `frontend/user-h5/` 从零初始化，初始化完成后再在本文件补充安装、开发、构建命令。
- 商家端为桌面 Web 后台（React 18 + Vite + Ant Design 5），位于 `frontend/merchant-admin/`，运行方式见该目录自己的 README。
- Java 后端位于 `backend/`；接口与联调口径以 `docs/backend/后端接口契约.md`、`docs/backend/后端任务分配与联调清单.md`、`docs/backend/后端联调验收用例.md` 为准。

## 2. 文档阅读与协作入口

- 阅读入口：`docs/README.md`（分角色阅读路径）、`docs/project/项目目录索引.md`（目录职责索引）。
- 唯一有效 PRD：`docs/PRD.md`；视觉与交互基线：`docs/design/`（`设计系统-用户端.md`、`设计系统-商家端.md`）；实现转写以 `docs/design/exports/**` 设计稿代码导出为准。
- 小组协作、问题单与 PR 流程：`docs/project/小组协作与提交流程.md`。
- 分工与里程碑：`docs/project/分工与里程碑安排.md`；每日进度：`docs/record/daily/YYYY-MM-DD.md`（记录规则见 `docs/project/项目规则.md`）。

## 3. 范围说明

- 本仓库当前负责课程文档；用户端 Vue 工程后续按 PRD 与接口契约在 `frontend/user-h5/` 从零初始化。
- 真实 Java 后端、数据库脚本和后端测试在 `backend/` 目录完成，完成状态以实际源码、测试和联调记录为准。
- 商家端为桌面 Web 后台（React 18 + Vite + Ant Design 5），在 `frontend/merchant-admin/` 实现；桌面优先 ≥1280px，不做移动端。
- 课程基础 P0 共六类：用户、商家（含商家注册）、店铺、商品、购物车、基础订单；P0 订单状态为单一状态字段，创建后仅 `PROCESSING`、不流转。
- 库存一致性、商家接单与订单状态推进（细分状态）、模拟支付均为已选 P1 扩展，不是 P0。
- 平台客服已移除；订单中的“联系商家”保留为用户到商家的会话。
- 支付为前端/系统模拟反馈，不接第三方支付；支付失败页只保留重新支付，支付成功页只保留查看订单和回首页。

> **填写责任人**：后端同学（部署脚本与局域网演示环境归属见 `docs/project/分工与里程碑安排.md`）。本节只列既有约束和必须回答的问题，**不预设具体方案**；由后端同学结合课程要求、实际服务器情况和小组习惯确定后填写。填写之前，任何人不以本节为部署决策依据。

### 4.1 既有约束（无论选哪种方案都成立）

- 代码在各成员本地电脑编写，通过 Git 分支 + PR 协作（见 `docs/project/小组协作与提交流程.md`）；服务器只承担"运行"（数据库、后端服务、演示访问），不承担"写代码"。
- 建表 SQL 与种子数据跟随后端工程维护（规划路径 `backend/database/schema/`），须可重复执行并可重置演示数据（PRD §7.18）。
- 数据库密码、服务器密码与密钥不写入提交代码（PRD §7.18），也不发群聊。
