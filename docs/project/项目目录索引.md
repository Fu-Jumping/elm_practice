用户端移动 H5（Vue 3 + Vite + Pinia）放 `frontend/user-h5/`，商家端桌面 Web 后台（React 18 + Vite + Ant Design 5）放 `frontend/merchant-admin/`，Java 后端放 `backend/`（数据库脚本跟随后端工程维护）。各端独立工程、独立进程，通过 RESTful 接口通信；不得把后端或商家端代码写进用户端前端工程目录。后端当前包含 `src/`、`database/schema/`、`database/seed/` 和 `pom.xml`；演示图片素材包另存仓库根 `demo-images/`（组长提供，含《图片清单.md》对照表），前端 `frontend/user-h5/public/demo-images/` 为页面伺服副本（2026-09-07）。本期范围（2026-09-09 决议，页数按负责人 2026-09-15 拍板口径）：除平台管理员外全部 P1/P2 在两前端工程内实现（用户端扩展服务 **14 页**（新增 AI 点餐助手对话页）、商家端扩展经营与消息 **6 页**（评价管理与评价回复合并，基础管理 7 页 + 扩展 6 页 = 合计 13 页）），平台管理员不新增页面、接口与目录。

用户端 E2E（2026-09-08 新增）：用例目录 `frontend/user-h5/e2e/`（`vitest.config.ts` 已 `exclude: e2e/**`），配置 `frontend/user-h5/playwright.config.ts`（`channel: 'chrome'` 复用本机 Chrome；`webServer` 自动拉起 mock 模式 dev server，无需后端），运行 `npm run test:e2e`；产物 `test-results/`、`playwright-report/` 已 gitignore 不入库。
