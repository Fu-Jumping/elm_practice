## 2. 原因

- `frontend/user-h5/src/views/user/StoreDetailView.vue` 的 `.cart-popup` 原为
  `bottom: calc(72px + env(safe-area-inset-bottom))`（原 :1036），而 `.cart-bar` 高度为 `64px`（:1128-1143）：
  72 = 64 + 8，抽屉被刻意抬高 8px（疑为 `--spacing-gutter` 间距），但抽屉是浮在底栏**上方**，这 8px 就成了可透视的缝。
- 遮罩 `.cart-popup-mask` 为 `inset: 0`、`z-index: 30`，购物车栏 `z-index: 20` 在其下，
  因此缝隙与底栏都被遮罩压暗，读起来像"抽屉下面缺了一块"。

## 3. 修复

- `.cart-popup`：`bottom` 改为 `0`（贴视口底端并盖住购物车栏）；底部内边距改为
  `calc(12px + env(safe-area-inset-bottom))`（贴底后「合计」行避开安全区）。`.cart-bar`、遮罩、z-index 一律未动。
- 提交顺序（严格红在前）：`test:` `4352ba1` → `fix:` `386a0d0`。
- 新增回归护栏：`frontend/user-h5/e2e/store-detail-cart-drawer.spec.ts`（只断言几何结果：底边间距、抽屉高 vs 底栏高、视口最底像素归属）。
