## 更正：env 文件缺失的根因已查明——是仓库根 `.gitignore` 的 `.env.*` 规则静默忽略所致

上一条评审中断言「这两个文件未被 .gitignore 忽略，应属遗漏提交」，**该判断有误，特此更正**。

经实测（`git check-ignore -v`）：**仓库根目录 `.gitignore`**（首版基线提交引入）中的 `.env` / `.env.*` 规则对全仓库生效，把 `frontend/user-h5/.env.development` 与 `.env.example` 一并忽略——创建的文件在 `git add` 时被静默跳过，`git status` 中不可见，导致本 PR 缺失这两个文件。本机建过文件≠已提交，属于工具链静默坑，不是作者意图问题。
