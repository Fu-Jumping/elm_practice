- 成员随 Git 提交附带记录，或把片段放入本目录的**按天文件夹**（`YYYY-MM-DD/`）；**AI 代理每轮工作结束的留痕片段（进度事实 + AI 使用点）同样写入本目录（2026-09-05 起），禁止直接写 `docs/record/daily/**`**。

- **过渡口径**：2026-09-10 当天已按旧命名（`<成员或角色>-HHmm.md`）落盘的成员，当天剩余轮次追加到其中**最后一个文件**，次日起统一用新命名；**既有片段不改名、不移动、不删除**。细则见 `docs/project/项目规则.md` §2 第 2 条 2.1–2.3。
- 落盘即永久留档：任何人**不得删除或移动**其中片段；次晨汇总只读取本目录与 git 提交信息，整合进 `docs/record/daily/` 正式记录。
