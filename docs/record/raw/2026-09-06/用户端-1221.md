## 规避决策（容易遗忘）

- **IAB 浏览器对非默认宽视口（<390）的截图合成有 bug**（多份页面平铺花屏，DOM 快照证实页面单份正常；≥390 宽正常）。320/360/375 的视口验收用只读 JS 指标（scrollWidth/getBoundingClientRect/行高）替代截图；下次真机或换 CDP 后补截图。
- **IAB clip 裁剪截图同样触发平铺伪影**：裁剪区右侧出现的"第二份页面"是物理像素平铺，非真实 DOM；判断以 DOM 几何测量（getBoundingClientRect）与整页截图为准。
- **底栏 Home Indicator 布局缺陷（负责人 9/6 指出）**：指示条最初作为 flex 行内第五个子元素参与布局，被挤到右侧（x=256）且四个 Tab 被压窄。修法：`position:absolute + left:50% + translateX(-50%)` 钉在底栏正中最低处（`bottom: calc(9px + safe-area)`），底栏 padding-bottom 改 26px 预留指示条区，四个 Tab 恢复整行等分。修复后实测：指示条 x=128 居中、bottom=843（设计稿 838–843），四 Tab 各 98px、中心 49/146/244/341 与设计稿等比对齐。教训：小尺寸截图区域目检不可靠，布局验收须配 DOM 几何测量。
- **mock 响应禁止返回内部裸引用（负责人 9/6 页面实测发现"加购只能成功一件"）**：mock POST 合并数量后返回内部存储对象的原引用，二次加购时 mock 直改裸对象 quantity（绕过 Vue 代理不触发），组件再以同引用 upsert 时 Vue 判定"新旧代理同源"跳过触发 → store 状态已变而 DOM 永久冻结在旧值。修法：mock 所有响应逐行返回浅拷贝（`{ ...line }`，对齐真实后端 JSON 序列化语义）；配套 XA-05 加购进行中按钮禁用（cartStore.addingProductIds）+ 加购成功本地 upsert 不再逐次 GET 重查。教训：**mock 是 HTTP 的替身，响应对象一律当新对象发**；排查手法为 store 状态与 DOM 对照插桩（store 变/DOM 不变 = 响应式触发丢失）。
- **门店封面改渐变占位（负责人 9/6 拍板）**：素材库仅一张封面图导致五店同图。改法：StoreCover 组件——有图走图，无图按 PRD"图片为空显示占位图"口径渲染品牌橙渐变 + 店名首字（色相按店名散列稳定区分）；mock 移除 image 字段。答辩口径：门店真实图片属图片上传扩展/后端种子数据。同轮把"缺配字段"从麦当劳的商品预览换成优惠标签（现实合理：无优惠活动），消除演示时"店里没有食物"的观感，T8 降级断言同步改断 couponTags 隐藏。
