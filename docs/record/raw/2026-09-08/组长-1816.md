## A. 进度事实

- **按负责人要求排查「实现与设计稿的外观取舍不一致」**，重点找「设计稿通栏布局被实现成卡片」一类问题。结果汇总到本地归档 `docs/_archive/2026-09-08-实现与设计稿外观取舍差异排查.md`（gitignore，本地留档）。
- **判定口径**：`docs/frontend/UI复刻经验与执行约定.md` §2.2「卡片化与嵌套滥用」——设计稿没有卡片壳就不要加壳；判断是否卡片看圆角 + 阴影 + 边框 + 背景色 + 父级 padding 的组合。
- **方法**：4 个并行子代理逐页比对设计稿代码导出（`docs/design/exports/用户端/**`；首页以 `02-首页/02-首页-精细/` SVG + 图层规格 CSS 为页面级真源）与 `frontend/user-h5/src/views/user/*.vue` 的分区结构与 CSS；关键结论由组长抽查复核（`.co-card/.ol-card/.od-card/.mn-profile/.mn-menu/.al-card/.ae-card` 的 radius 与 margin 均已核对）。
- **核心结论**：
  - **12 处「通栏白色分段」被实现成 `radius 8px + 左右 12px 外边距` 的卡片**：确认订单 4 处（收货地址/送达时间/商品明细/备注）、订单列表 1 处（订单卡）、订单详情 3 处（状态区/收货信息/商品金额明细）、我的页 2 处（用户信息区橙通栏→白卡、功能入口分组）、地址列表 1 处（地址卡）、新增地址 1 处（表单区）。根因是通用卡片类 `.co-card/.ol-card/.od-card/...`。
  - **同类变体 3 处**：商家详情「点餐/评价 Tab」被 8px 灰缝切成独立白条（稿为与横幅同底通栏 + 1px 分隔线）；商品图圆角 2px→8px；我的页退出登录按钮自加卡片壳。
  - **结构级缺失**：订单列表筛选栏、订单详情底部操作区、地址列表「新增地址」固定底栏、新增地址「保存」固定底栏、我的页会员权益横幅与三列统计卡、登录/注册输入框与按钮样式。
  - **尺寸系统性缩水**：商家详情顶栏 44↔56、购物车栏 56↔64、多处字号小一档；首页搜索框高/边框、商家卡标签高、分类宫格第 2/3 行列心漂移（间距 53.5–89.5px vs 稿 74–75px）。
  - **首页无卡片化问题**（通栏三段保留正确、白卡无阴影与稿一致）。
- **性质说明**：以上均为外观取舍层面，不影响功能正确性；本次排查未改任何代码。建议处理顺序已写入归档文件（演示前先修确认订单/订单列表/订单详情的 8 处，肉眼一眼可见）。
