**断言 B｜多视口断言（320 / 360 / 375 / 390 / 430）**

### 4.2 TODO-USER-024｜设计稿像素比对脚本与一次性取证

**目标**：把"实现截图 vs 设计稿导出"的像素比对做成可复跑的一次性取证工具（**不是 CI 门禁**），用于结课汇报的"保真度分区指标"与前后对照图。

**放哪（推荐）**
- 截图脚本：`frontend/user-h5/scripts/shot-design-compare.cjs`（Playwright + 本机 Chrome：`channel: 'chrome'`、`--no-proxy-server`；视口 **393×852 @2x**；关闭 animation/transition，等 `document.fonts.ready` 后静置约 1.5s 再截图）；
- 比对脚本：`tools/design-diff/pixel_diff.py`（Python 3.12 + Pillow + numpy，**零 npm 新增依赖**，本机已验证可用）；
- 产物：`test-results/design-diff/`（截图、diff 图、分带指标 JSON），**不入库**；结论写 raw 片段与 PR 描述。

**三条必须遵守的口径（否则数字没有意义）**
1. **53px 状态栏偏移校正**：设计稿画布把 9:41 状态栏画了进去，而 H5 实现不含（见 `docs/design/exports/用户端/02-首页/02-首页-精细/README.md` §2.3）→ 比对前必须把设计稿的 y 起点下移 53px（@2x 为 106px）。
2. **数据驱动区域必须掩膜**：商家卡等区域渲染真实数据，与设计稿占位内容天然不同（实测该区域差异 33.3%）；不掩膜会把"内容不同"误报成"复刻不准"。建议用 Playwright `mask` 或按坐标裁掉后再比。
3. **整图比对只对"画布 393 的精细版"做**：`screen.png` 共 29 张、**15 种尺寸**，多数是 390 宽或被高度裁切的基线；只有首页/启动页精细版是 786×1704（393×852@2x）可直接对齐。其余页面只做**分带指标**（按设计稿 CSS 的 top/height 切带比较），不做整图百分比。

**输出内容（一次取证）**
- 整图指标：超阈像素占比、平均绝对差、最优整体位移（`dx/dy`）；
- 分带指标：定位栏 / 搜索区 / 分类宫格 / 活动区 / 筛选标签 / 商家卡（掩膜前后各一份）；
- diff 可视化图（差异标红、其余灰度）；
- 一句结论：**主门禁是几何/色值/结构断言，像素比对只用于取证**。

**参考实现（本机已有，直接改写，不要从零写）**
- `docs/_archive/presentation/调研报告/第二轮与第一轮原始报告/第二轮/原型-截图比对/`：
  - `shot.cjs`（截图；参数：base/路径/宽/高/DPR/输出）；
  - `pixel_diff.py`（整图 diff + 差异图）；

**验收标准**
1. 一条命令可复跑：截图 → 比对 → 输出指标与 diff 图；
2. 首页结果与参考实现一致（容差 ±0.5 个百分点），并在 README 或脚本注释里写明上述三条口径；
