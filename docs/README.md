# 文档阅读入口

日期：2026-09-01

本目录根层保留核心文档和阅读入口；小组协作、后端联调文档按用途放入 `docs/project/**`、`docs/backend/**`；工作过程与 AI 使用记录在 `docs/record/**`（规则见 `docs/project/项目规则.md`）；设计系统与原型资产在 `docs/design/**`、`docs/prd-assets/**`。`docs/PRD.md` 是唯一有效 PRD。

## 3. 展示同学重点看

| 文档 | 用途 |
| --- | --- |
| `docs/project/小组协作与提交流程.md` | 发现前端问题时如何反馈，想改代码时如何提 PR |

课程报告的产品范围和完成状态只引用 `docs/PRD.md`；如需写“测试与问题修复”章节，由组长从历史记录中摘录已验证事实。发现前端问题时，先交问题单和截图；会代码时也必须走分支和 PR，由组长合并。
