## 3. P0 接口交付顺序（联调节点）

后端按以下顺序交付，前端逐段关闭 Mock 回退；字段、请求体、状态机以契约为准：

1. 用户注册/登录/注销/当前用户：`/api/v1/users`、`/api/v1/auth/login`、`/api/v1/auth/logout`、`/api/v1/me`
2. 店铺和商品查询：`/api/v1/stores`、`/api/v1/stores/{storeId}`、`/api/v1/stores/{storeId}/products`
3. 地址维护：`/api/v1/me/addresses`
4. 商家登录和店铺管理：`/api/v1/merchant/auth/login`、`/api/v1/merchant/store`
5. 商家分类和商品管理：`/api/v1/merchant/categories`、`/api/v1/merchant/products`
6. 购物车：`/api/v1/cart`、`/api/v1/cart/items`
7. 创建订单：`/api/v1/orders`
8. 订单列表/详情/明细：`/api/v1/orders/**`
9. 商家订单查询（P0，2026-09-02 负责人拍板，免评审）：`/api/v1/merchant/orders`、`/api/v1/merchant/orders/{orderId}`
10. P1 模拟支付：`/api/v1/orders/{orderId}/payment`

创建订单必须写入订单头、明细快照、地址快照和金额字段，不得只返回订单号。

## 4. 联调 Checklist（按页面）

| 顺序 | 页面 | 验证点 |
| --- | --- | --- |
| 1 | `/login` | 真实登录成功进入首页 |
| 2 | `/` | 首页商家来自真实接口 |
| 3 | `/merchants/m002` | 商家详情和商品来自真实接口 |
| 4 | 商家详情购物车 | 加购、改数量、删除后接口同步 |
| 5 | `/checkout?storeId=m002` | 地址、商品和基础金额能显示 |
| 6 | `/orders` | 新订单出现在列表 |
| 7 | `/orders/:orderId` | 订单明细、地址和基础状态正确 |
| 8 | 支付环节（Mock 演示页，无固定路由） | 选定支付扩展后，模拟支付状态正确更新 |

P0 通过后再测：用户评价、用户消息、商家端订单推进、商家端商品上下架、商家端优惠影响用户结算。
