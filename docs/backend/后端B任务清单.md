## 写作纪律速查（摘自 SRS §0）

1. **引用不复述**：PRD 已写死的规则（如 7.4 优惠计算顺序、7.6 订单状态表）只写"见 PRD 7.x"；接口字段引用《后端接口契约》章节号。
2. **异常边界全集**：每个功能需求枚举完整的异常与边界条件（缺参、非法值、越权、资源不存在、状态冲突、重复提交）。
3. **可测验收条目**：每条需求带"正常场景 + 异常场景"验收条目。

功能需求 FR 建议格式：

```
FR-xx <名称>（来源：PRD 7.x；接口：契约 3.x）
描述：<输入 / 处理 / 输出>
正常验收：<条目>
异常验收：<逐条枚举：缺参、非法值、越权、资源不存在、状态冲突、重复提交>
```
